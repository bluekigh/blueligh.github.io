# 게임 개발의 첫 지도

과정 1의 공통 지식을 선행 관계로 탐색하는 한국어 학습 안내입니다. 현재 범위는 14개 본 학습 주제와 Git 별도 참고 자료의 세부 목차, 핵심 개념, 사례, 요청 예시, 이해 확인입니다. 상세 교재와 과정 2 실습은 후속 작업입니다.

## 파일

- `index.html`: 공통 화면 틀.
- `curriculum.js`: 고정 ID, 선행 관계, 배치, 학습 내용. 새 항목과 문서는 여기에서 관리합니다.
- `app.js`: 로드맵 연결선, 해시 주소 탐색, 읽음 기록.
- `styles.css`: 데스크톱·모바일·인쇄 화면.

외부 패키지, 빌드, 서버 데이터베이스가 필요하지 않습니다. HTML을 직접 열거나 정적 웹 서버에서 실행할 수 있습니다. GitHub Pages에는 이 폴더를 그대로 게시합니다.

## 게시 파일 갱신

`index.html`의 CSS·JavaScript 주소에는 파일 내용의 SHA-256 앞 12자리를 `?v=`로 붙입니다. 해당 파일을 수정할 때 이 값도 함께 갱신합니다. 이전에 방문한 브라우저가 예전 배치나 연결선 파일을 재사용하지 않도록 하기 위한 구분입니다. 기존 탭은 게시 후 새로고침해야 갱신됩니다.

## 링크와 선행 관계

주제 주소는 `index.html#/lesson/04`와 같은 형태입니다. GitHub Pages에서 새로고침하거나 직접 공유해도 서버 경로 오류가 발생하지 않도록 해시 주소를 사용합니다. 주제 ID는 바꾸지 않습니다. 화면 번호는 본 학습 주제의 순서에 맞춰 별도로 계산합니다. 기존 Git 주소 `#/lesson/04`와 읽음 기록은 유지됩니다.

`reference: true`인 항목은 별도 참고 자료로, 연결선·추천 순서·본 과정 진도에서 제외합니다. Git은 다른 본 학습 주제의 선행 조건에 넣지 않습니다.

데스크톱 배치는 4개 카드 열을 기준으로 하며, `col`의 0.5 간격으로 공통 기초 항목을 가운데 정렬합니다. 아래쪽은 저장·콘텐츠·품질의 연결 관계에 맞춰 배치합니다. 항목 번호와 선행 관계는 위치와 독립적으로 유지합니다.

연결선은 가로·세로 직선으로만 그립니다. 여러 선을 하단에서 따로 출발시키려면 출발 주제에 `splitBottom: true`를 지정합니다. 목적지의 좌우 순서에 맞춰 하단 출구를 균등하게 나누며, 위쪽 진입점도 출발 주제의 좌우 순서에 맞춰 배치합니다. 바깥 오른쪽 통로로 우회하는 연결은 도착 주제의 `routes`에 선행 ID별로 `outer-right`를 지정합니다. 과정 2 안내는 본 학습의 마지막 주제 하단에만 표시합니다.

`prerequisites`에는 직접 권장하는 선행 주제만 기록합니다. 전체 선행 경로는 이 관계에서 계산합니다. 순환 연결을 만들지 않습니다. 선행 주제를 읽지 않았어도 모든 항목을 열 수 있습니다. 모바일에서는 번호순 목록과 선행 링크로 같은 관계를 제공합니다.

읽음 표시는 해당 브라우저의 `localStorage`에만 남습니다. 계정·기기 간 동기화나 학습 평가 결과는 제공하지 않습니다. 저장이 차단된 환경에서도 열람할 수 있습니다.

화면 이름을 표시하는 개발용 안내는 파일 직접 열기와 localhost에서만 보이며 공개 사이트에서는 숨깁니다.

## 검토할 항목

1. 모든 주제 ID와 선행 링크가 유효하고 순환하지 않는지.
2. 지도 → 주제 → 선행 주제 → 지도 탐색과 브라우저 뒤로 가기.
3. 읽음 표시·취소와 새로고침 이후 유지.
4. 직접 주제 주소로 접속, 잘못된 주소 안내, 모바일 가로 넘침.
5. 공개 주소에서 개발용 화면 이름이 숨겨지는지.
